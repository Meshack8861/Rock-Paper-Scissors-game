     Rock Paper Scissors Game
A web application that lets users play the classic game of Rock, Paper, Scissors against a randomized computer opponent. 
Built entirely using HTML< CSS and JavaScript.

    Features
1.Real-time Logic: Instantly calculates game outcomes (Win, Loss, or Draw) using standard game rules.

2.The computer randomly selects its move each round to ensure fair gameplay.

3.Modern UI: Features a centered layout, linear gradient background, and interactive button hover effects.

    Project Structure
The project relies on three linked files:

1.index.html – Defines the structural layout.

2.style.css – Handles the visual styling.

3.script.js – Contains the game logic, computer choice generation, and DOM updates.

   Setup Instructions
Because this is a static frontend project, it runs directly in your web browser without requiring a local server, terminal 
installations.

1.Download the Files: Save index.html, style.css, and script.js together in a single folder on your local computer.

2.Verify File Paths: Ensure all three files remain in the exact same directory so their internal links function correctly.

3.Launch the Game: Double-click the index.html file (or right-click and select Open With) to launch it in any modern web browser (such as Chrome, Firefox, Safari, or Edge).

   Usage Notes
1.Making a Move: Click any of the three action buttons—Rock, Paper, or Scissors—to submit your choice.

2.Viewing Results: The app will immediately display your choice next to the computer's choice, followed by the final round verdict (You Win!, Computer Wins!, or It's a Draw!).

3.Replaying: To play another round, simply click any button again. The game updates instantly without needing a page refresh.

 Note: Game states and scores are not tracked across sessions. Refreshing the browser window will clear the currently displayed result and reset the board.
